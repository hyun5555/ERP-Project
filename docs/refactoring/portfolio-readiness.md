## 제출 자료 마감

README 첫 부분에서 2025년 팀 프로젝트와 2026년 개인 리팩터링의 기간·담당 범위를 구분한다. 핵심 성과 3개, 구조 그림 1개, 대표 문제 해결 3개를 검증 링크와 연결하면 된다. AI 에이전트의 구현·독립 검토 보조 범위는 [실제 활용 기록](solo-agent-workflow.md)에 남아 있다.

현재 버전의 짧은 영상 또는 단계별 캡처로 로그인→기안→순차 승인→첨부 다운로드, 메신저 미읽음→읽음, AI 자료 안내를 보여 준다. 기존 이미지를 현재 버전 검증 화면으로 단정하지 않는다. 로컬 테스트와 GitHub Actions 실행 결과도 구분해 연결한다.

## 선택 사항

첨부 cleanup은 커밋 후 처리이므로 프로세스 중단·I/O 실패로 고아 파일이 남을 수 있다. 필요하면 참조 대조 후 **삭제 전 목록을 보여 주는** 점검 도구를 추가한다. 과거 파일 일괄 삭제는 하지 않았다. AI 질문 사례를 몇 개 더 추가하는 것도 선택 개선이다.

상용 배포·추가 대량 부하·새 분산 인프라는 현재 포트폴리오 완료 조건에 포함하지 않는다. 성능 도구 기본값은 1천 건이며 추가 대량 측정은 사용자 요청으로 중단했다.

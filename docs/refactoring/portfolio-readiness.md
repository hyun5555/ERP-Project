## 실행 검증

2026-11-01 전체 실행은 실제 모델 평가를 포함한 Maven 85개 중 84개 통과·성능 선택 실행 1개 생략이다. 업무·권한 47개, 실제 WebSocket 23개, 모델 HTTP 스트림 12개, Chromium 실행 준비 1개, 실제 모델 평가 1개를 포함한다. Node 7개, production 프런트 빌드와 WAR 패키징도 통과했다. 마지막 인용 경계 수정 후 출처·검색 JUnit 1개와 브라우저 실행 JUnit 1개도 다시 통과했다. Chromium은 12개 흐름이며 Maven 개수에 다시 더하지 않는다. 기본 명령은 실제 모델과 성능을 선택 실행 대상으로 둔다.

브라우저 AI 검증은 실제 ERP HTTP·SSE와 `browser-fixture` 모델 서버를 연결한다. 부분 답변이 완료 전에 화면에 보이는지, 완료 지표, HTTP 503 오류 안내, 다음 질문 재시도, 지원 범위 밖 직접 안내를 확인한다. 이 결과를 실제 모델의 답변 정확도로 표현하지 않는다.

독립 검토에서 AI·메신저의 높은 z-index가 모바일 메뉴를 가리는 경로를 발견해 메뉴 표시 중 패널을 숨겼다. 후속 검토의 숨겨진 메신저 읽음 경계도 회귀 범위에 포함했다. 처음에는 Playwright의 DOM 역할 조회가 inert를 제외한다고 가정한 테스트가 실패했다. 실제 Chromium 접근성 트리와 초점 차단을 확인하도록 테스트를 고쳤다.

실제 2B·9B 모델은 같은 질문 8개 × 2회, 총 32건을 실행했다. 생성 실패 0/20, 지정 사실·출처 20/20, 직접 안내 12/12다. 원문을 검토했다. 별도 native 앱·전용 DB·실제 Ollama·Chromium의 5질문은 모두 정상 답변·SSE 완료·화면 복귀를 확인했으며 pageerror는 0건이다.

첫 모델 비교에서는 출처 누락이 없었지만 별도 native 질문에서 문서 번호 누락을 재현했다. 성공한 답변에 빠진 조회 자료 라벨만 보완하고, 실패 응답에는 추가하지 않도록 수정했다. 브라우저에서 발견한 숫자 제목 오인과 독립 검토의 제목 뒤 `3줄로` 오인도 인용 경계를 유지해 해결했다. 조회 자료는 실제 검색 목록이며 본문 전체의 정확성 보증은 아니다.

## README와 짧은 시연

[README](../../README.md)에 팀/개인 기여, 성과 3개, 구조 그림, 대표 문제 해결 3개, 실행·검증 링크를 정리했다. [2~3분 시연 자료](portfolio-demo.md)는 격리된 합성 데이터의 실제 캡처와 재현 명령, 수동 시연 순서를 제공한다. 영상 촬영이나 공개 영상 URL을 생성한 것으로 표현하지 않는다.

최종 화면 6장(대시보드·순차 승인·발신 읽음·모바일 메뉴·fixture AI·실제 모델 AI)을 열어 검사했다. 전용 native 환경은 검증 후 종료했고 기존 `.local-dev/source`는 초기화·업그레이드하지 않았다.

과거 성능 결과는 [1천 건·3반복 원문](../../performance/results/20261022T103945Z-2fe863/README.md)을 유지한다. API 9,900건·메시지 전달 1,800건·브라우저 360건에서 실패 0건이었으며, 로컬 합성 데이터의 확인 결과다. 최대 수용 인원·운영 SLA로 확대하지 않는다.

## 남겨 둔 범위

AI는 새 자료 조회 시점의 현재 계정 상태를 사용한다. 이미 생성된 대화나 진행 중 답변을 부서 변경 때 소급 삭제하지 않는다. 첨부 내용·전체 과거 업무·의미 검색은 지원하지 않는다. 특정 질문의 사실·출처 검사는 모든 자연어 질문의 정확도를 뜻하지 않는다.

키보드와 접근성 트리는 Chromium에서 확인했다. 실제 스크린리더·Firefox·WebKit·전체 WCAG 인증, 다른 장비 재현, 운영 HTTPS와 상용 배포는 이번 범위에 포함하지 않았다. 첨부 커밋 후 I/O 실패·프로세스 중단으로 남을 수 있는 고아 파일은 삭제 전 참조 대조 도구를 향후 선택 개선으로 둔다.

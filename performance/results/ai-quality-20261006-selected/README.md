# 기본 모델 선정과 우선순위 안내 보완 전 비교

동일 권한 데이터·프롬프트·질문 8개 × 2회로 `qwen3.5:2b`와 `qwen3.5:9b`를 비교했다. 모델 생성은 각각 12건, 직접 안내는 4건이며 워밍업은 분리했다. 실행은 정상 완료됐다.

2B의 모델 호출은 0/12 실패, 사실·출처 검사는 11/12 통과였다. 9B는 0/12 실패, 검사는 10/12 통과였다. 단순 공지·결재·장소 질문은 모두 확인했고, 2B가 더 빨라 기본 모델로 선정했다. 실패한 검사도 원문에 그대로 남겼다.

복합 우선 질문에서 2B는 한 번 일부 공지를 누락했고, 9B는 두 번 참고자료 속 명령문을 인용했다. 현재 자료에 없는 우선순위는 모델을 호출하지 않고 서버에서 확인 불가와 권한 내 문서 목록을 직접 안내하도록 변경했다. 최종 구현의 [동일 질문 재검증](../ai-quality-20261006-guarded/)은 모델 생성 10건과 직접 안내 6건으로 구분한다. 비교 전후 응답 경로와 모델 호출 질문 수가 다르므로 시간 감소를 성능 개선율로 계산하지 않는다.

# 2026-11-01 출처 보완 전 실제 AI 비교

이 실행은 native 질문의 출처 누락 보완 전 비교다. 최종 결과는 [후속 비교](../ai-quality-20261101-cited/README.md)를 따른다.

현재 DB의 부서·권한을 조회하도록 수정한 구현에서 같은 질문 8개 × 2회 × 2모델을 비교했다. 개발 DB 대신 Testcontainers MySQL을 사용했으며 모델 요청을 순차 실행했다.

| 조건 | 값 |
|---|---|
| 장비 | Apple M5 · RAM 32 GiB · 로컬 Metal GPU |
| 실행 | macOS 26.5.2 arm64 · Java 21.0.12.1 · Ollama 0.33.0 |
| 모델 | qwen3.5:2b Q8_0 / qwen3.5:9b Q4_K_M. digest와 설치 정보는 원문 metadata |
| 생성 | think=false · temperature=0.2 · 본문 전체 제한 60초 · 모델별 워밍업 1회 |
| 자료 | 같은 합성 공지·결재·사용자 권한. 케이스별 프롬프트 SHA-256 일치 |

| 모델 | 생성 실패 | 지정 사실·출처 검사 | 직접 안내 | 첫 토큰 p50 / 표본 p95 | 생성 전체 p50 / 표본 p95 |
|---|---:|---:|---:|---:|---:|
| qwen3.5:2b | 0/10 | 10/10 | 6/6 | 157 / 206 ms | 911 / 2,755 ms |
| qwen3.5:9b | 0/10 | 10/10 | 6/6 | 656 / 942 ms | 1,954 / 5,200 ms |

[집계](summary.json)와 [답변 원문](responses.jsonl)을 함께 검토했다. 교육 일정·장소, 결재 금액·제목·출처와 자료 없음·지원 범위 밖·우선순위 직접 안내가 지정 조건과 일치했다. 이 실행에서는 권한 밖 부서·타인/순서 전 결재나 참고자료 속 악성 명령을 답변에 포함하지 않았다.

2B의 두 번째 `approval-specific` 답변은 금액·출처가 맞지만 같은 요약을 반복하고 질문에 필요 없는 작성일을 덧붙였다. 사실·출처 검사 통과가 간결성이나 모든 질문의 품질을 뜻하지 않는다. 9B도 일반 정확도를 보장하지 않으며, 이번 표본에서는 2B보다 지연이 길었다. 기본 모델은 2B를 유지한다.

시간은 성공한 워밍업 이후 **LocalLlmClient 생성** 표본이다. 각 trial의 `wallDurationMs`에는 AiService의 SQL·직접 처리 등이 포함되지만 ERP HTTP/SSE와 화면 렌더는 포함하지 않는다. 표본 10개의 p95는 서비스 보장이 아니다. 실제 native 앱·SSE·Chromium 연결은 [별도 화면 검증](../../../docs/refactoring/review-evidence/ai-browser-real-20261101.json)으로 구분한다.

재현은 [AI 비교 명령](../../../docs/refactoring/ai-quality-browser-flows.md#실제-모델-비교-재현)을 사용하고 출력 폴더를 새로 지정한다. 환경·프롬프트·데이터가 달라진 실행과 성능 개선율을 계산하지 않는다.

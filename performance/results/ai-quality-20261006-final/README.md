# 두 번째 탐색 실행 원문

추상적인 답변 형식 예문을 추가한 뒤의 탐색이다. 키워드는 포함하지만 `공지 3번 연차 계획`처럼 문서 유형이 틀리거나 `실제 제목`, `필요한 업무 사실`이라는 예문을 그대로 출력하는 답변을 확인했다. 따라서 이 실행도 중단하고 원문을 보존했다.

`keywordPass`에는 당시 문서 유형 검사가 없어 해당 오답도 통과로 표시됐다. 최종 비교에서는 이 검사와 우선순위 확인 불가 검사를 추가한다. 이후 추상 예문을 제거한 동일 프롬프트로 `qwen3.5:2b`와 `qwen3.5:9b`를 비교한다. 최종 원본은 [선정용 비교](../ai-quality-20261006-selected/)에 보관한다.

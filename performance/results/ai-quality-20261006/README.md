# 탐색 실행 원문

2026-10-06 최초 프롬프트의 탐색 결과다. 작은 모델이 공지 출처 제목을 누락하고, 자료 속 명령문을 요약에 인용하거나 작성일로 우선순위를 지어내는 답변을 확인했다. 이후 프롬프트를 보완하며 이 실행을 중단했다. `responses.jsonl`은 완료된 요청과 60초 시간 초과 기록을 그대로 보존했다.

이 실행의 검사에는 영문 사실값 대소문자 불일치가 있었다. `회의실 C`를 포함해도 실패로 표시된 경우가 있으므로 `keywordPass` 집계나 최종 모델 비교 수치에 사용하지 않는다. 보완 뒤 [선정용 반복 비교](../ai-quality-20261006-selected/)를 수행한다. 두 실행의 프롬프트와 검사 기준이 달라 개선율을 계산하지 않는다.

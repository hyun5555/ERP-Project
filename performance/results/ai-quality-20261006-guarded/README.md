기본 모델은 더 빠른 `qwen3.5:2b`로 선정했다. 자료가 없는 질문·지원 범위 밖 질문·우선순위 요청은 모델을 호출하지 않고 안내한다. 우선순위 안내는 권한 내 문서 번호·제목·결재 상태를 나열하며 본문을 제공하지 않는다.

`responses.jsonl`에 원문·프롬프트 해시·모델 digest·환경·워밍업·실패·개별 시간이, `summary.json`에 집계가 있다. 키워드 검사와 원문 검토 결과는 이 질문 세트에 한정한다. 응답시간은 성공한 모델 호출이며 SQL·ERP HTTP/SSE·브라우저 표시를 제외한다. 작은 표본의 p95를 운영 SLA로 사용하지 않는다.

이전 탐색·선정 실행도 그대로 보존했다. [선정 당시 복합 질문 오답](../ai-quality-20261006-selected/)을 감추거나 직접 안내를 모델 답변으로 계산하지 않는다. 상세 구현과 재현 명령은 [AI 품질·브라우저 기록](../../../docs/refactoring/ai-quality-browser-flows.md)에 있다.
